# Tracks Unfold

A mobile-first musical puzzle game about awakening an impossible instrument.

## Learning and design

Musical understanding through practice, memory and fluency through varied repetition, and keyboard familiarity as a secondary objective.

- [Learning principles](Learning%20principles.md): the project's learning priorities and guidance for design trade-offs.
- [Curriculum — skill map](Curriculum/Curriculum%20-%20Skill%20map.md): capabilities to develop and their learning foundations.
- [Curriculum — practical outcomes](Curriculum/Curriculum%20-%20Practical%20outcomes.md): what those capabilities enable in musical use.
- [Puzzle types](Puzzle%20Types/): playable interpretations of the curriculum, at their stated stages of design.

## Development

Use Node.js 24 and npm.

```sh
npm install
npm run dev
```

Run all validation with:

```sh
npm run check
```

Pushes to `main` are built and deployed to GitHub Pages.
