# H2 - Roman-numeral progressions

## Ability

Interpret and construct major-key Roman-numeral progressions; distinguish scale-degree numbers from chord numerals and read quality markings. Translate between named chords and numerals in a stated key. Place chord changes at specified beats and bars, account for each chord’s duration, and preserve that timing when realizing the progression.

## Builds on

- [[H1 - Diatonic triads in major]]

These are direct learning foundations, not requirements for perfect mastery. Backlinks show skills that build on this one.

## Scope and teaching notes

Chord order and chord-change timing are separate demands. The timing component additionally builds on [[R3 - Durations and rests]] and [[R5 - Meter and downbeats]]; do not gate introductory Roman-numeral work on full rhythmic fluency. Apply the same timing expectations when later using minor or seventh-chord progressions.

## Evidence of understanding

Assess the ability above in more than one example. Distinguish supported performance from independent performance, and naming from hearing or construction where relevant. A multi-skill task only provides evidence for relationships the player actually has to determine.
