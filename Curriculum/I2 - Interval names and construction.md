# I2 - Interval names and construction

## What this skill enables

Determine an interval’s number from its note letters, and its quality from its size; construct common major, minor and perfect intervals.

## Builds on

- [[I1 - Semitone distances]]
- [[P5 - Enharmonic equivalents]]

These are direct learning foundations, not requirements for perfect mastery. Backlinks show skills that build on this one.

## Scope and design notes

Count note letters for interval number and semitones for quality. C–D♯ and C–E♭ have the same sounding distance in the app but different interval names. Start with common spellings.
